mARine – Marine Biology AR App

Revolutionizing marine biology education through immersive AR!

Features

  • Complete AR Framework with 15+ integrated components
  • Intuitive Module Builder with drag-and-drop interface
  • Realistic Marine Life Simulation with natural behaviors
  • Environmental Control Interface with real-time sliders
  • Cross-platform support: Android (ARCore) & iOS (ARKit)
  • Human Pose Detection with MediaPipe
  • QR Code Sharing System for classroom modules
  • Immersive underwater atmosphere with dynamic lighting

Getting Started

For Educators & Students

  • AR-compatible mobile device with ARCore/ARKit
  • Minimum 4GB RAM, 2GB storage
  • Download and launch the app
  • Complete tutorials and explore modules

For Developers

  • Hardware: RTX 2050+, 8GB RAM, 25GB storage
  • Clone repository: git clone https://github.com/Catrobat/mARine.git
  • Open in Unity 6.0LTS or newer
  • Install dependencies: Vuforia SDK, MediaPipe Unity Plugin
  • Switch to Android/iOS in Build Settings, enable ARCore/ARKit
  • Deploy to AR device
